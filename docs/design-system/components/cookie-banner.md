# Cookie banner

Bottom-right card (full width minus 16px on mobile), max 560px.
- First layer: **Reject · Settings · Accept**, equal size and visual weight (Reject is not a text link). This follows the German DSK guidance and TTDSG §25.
- Text: "We use analytics cookies only if you agree. Essential cookies keep the site working. Details".
- No analytics, GTM or advisor funnel events before Accept; the existing gating stays as Clauco described.
- "Cookie settings" in the footer reopens the banner.
